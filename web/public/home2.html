安装教程

Codex 客户端配置

客户端
1
下载并安装 Codex 客户端
选择对应的操作系统版本安装官方客户端：
Mac 版 (.dmg) Windows 版 (.exe)
2
编辑本地配置文件
进入当前用户主目录的 .codex 文件夹下创建/编辑两个文件：
~/.codex/auth.json (或 C:\Users\用户名\.codex\auth.json)
{"OPENAI_API_KEY": "sk-你的专属Key"}
~/.codex/config.toml
model_provider = "yunxi" model = "gemini-3.7-flash" model_reasoning_effort = "high" disable_response_storage = true preferred_auth_method = "apikey" [model_providers.yunxi] name = "yunxi" base_url = "https://yxai.pro/v1" wire_api = "responses" requires_openai_auth = true
3
保存并启动客户端
保存文件后打开 Codex 客户端即可直接调用，如遇问题重启客户端即可。
💡 提示：Windows 下若看不到 .codex 目录，可在文件资源管理器中勾选“显示隐藏的文件/文件夹”。

Claude Code 客户端配置

客户端
1
下载并安装 Claude 官方软件
选择对应的系统版本，直接下载官方安装包：
Mac 版 (.dmg) Windows 版 (.exe)
2
设置环境变量/配置文件
将 API 路由与令牌写入环境配置中持久生效：
Mac / Linux: 编辑 ~/.zshrc 或 ~/.bashrc 追加
export ANTHROPIC_BASE_URL="https://yxai.pro" export ANTHROPIC_AUTH_TOKEN="sk-你的专属Key" export API_TIMEOUT_MS="300000"
Windows (PowerShell 环境变量配置)
[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://yxai.pro", "User") [Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "sk-你的专属Key", "User")
3
启动使用
打开软件或在终端中运行即可自动读取该配置，畅享 Claude 旗舰模型。
🚀 提示：令牌需以 sk- 开头，可在顶部导航“获取 API 令牌”直接添加。

cURL / 第三方软件配置

通用接入
1
桌面对话客户端参数
支持 Chatbox、NextChat、Cherry Studio 等，按如下参数填写：
# 接口地址 API Host = https://yxai.pro API Path = /v1 # 认证密钥 API Key = sk-你的专属Key
2
cURL 测试连通性
在终端直接发送请求测试连通性：
curl https://yxai.pro/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk-你的专属Key" \ -d '{ "model": "gpt-4o", "messages": [{"role": "user", "content": "Hello!"}] }'
📌 支持市面绝大多数 OpenAI / Claude 标准兼容软件，填入上方地址即可快速接入。
